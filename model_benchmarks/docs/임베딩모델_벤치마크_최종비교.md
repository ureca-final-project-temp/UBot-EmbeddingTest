## 모델별 총평

**BGE-M3 — 종합 1순위**
- Top-1/Top-3/Top-5/MRR/Hard Negative 5개 지표 전체 1위
- 속도 초당 100건, 상위권
- Hard 카테고리 유일하게 80%대
- 오타 정확도 100%

**EmbeddingGemma-300M — 리소스 제약 시 대안**
- 정확도 종합 2위 (Top-1 83.3%, MRR 89.4%)
- RAM·VRAM 사용량 5개 중 최소
- 속도는 느림 (초당 36건, qwen3-embedding과 유사)
- 원인: 디코더 기반(Gemma3) 아키텍처

**multilingual-e5-large — 무난한 3위**
- 전반적으로 안정적
- Hard 카테고리만 50%로 약함
- 오타 정확도 100% (BGE-M3와 동률)
- Ollama 미공식 지원 (커뮤니티 GGUF 필요)

**gte-multilingual-base — 속도 우선 시 고려**
- 속도 1위 (초당 155건)
- RAM 사용량 낮음
- 정확도 하위권
- 긴질문 카테고리 50%, 전체 최약점

**Qwen3-Embedding-0.6B — 이번 과제에는 부적합**
- 정확도 5위 (최하위)
- 속도 최하위 (초당 37건)
- RAM 사용량 최대 (2.4GB)
- 우위 지표 없음

## 전 모델 공통 관찰

- 구어체: 5개 모델 전부 100% (변별력 없음)
- 긴 질문: 전 모델 공통 최약점 (50~80%)
- 속도: 아키텍처(인코더 vs 디코더)가 파라미터 수보다 영향 큼
  - 인코더 전용(BGE-M3, e5-large, gte-multilingual-base): 빠름
  - 디코더 기반(Qwen3-Embedding, EmbeddingGemma): 느림
